# 工序 3：视觉动作与潜台词对白写作

> 电影首先是一门用摄影机拍出来的艺术。只把心理活动写成文学旁白或靠台词直白自爆，剧本就没有银幕感。

## 一、动作行：只写可拍、可听的现在时

1. **视觉外化情绪**：不写「他心里充满怨恨与悔意」，改写为可被摄影机拍下的动作，例如「他把没签字的协议折成细条，推进滚烫茶水里慢慢摁沉」。
2. **删掉孤立微动作套话**：减少单薄的「眼神微动」「若有所思」「嘴角微扬」，改为带明确意图或物理后果的调度。
3. **段落短小留白**：每段动作行控制在 2–4 行，像镜头分切一样自然换行，给页面留出呼吸节奏。
4. **音效写法**：关键声音细节（门锁咔哒、远处刹车刺响）自然嵌进动作行并适当突出；不用广播剧式 `SFX:` 或 `MUSIC:` 独占行。

## 二、潜台词对白：话在表面，刀在底下面

1. **拒绝“已知科普”**：两人吵架不互述双方早知道的陈年旧事；要用此时此刻的利益争夺撬出往事痕迹。
2. **各说各话的角力**：每人带着自己的小算盘说话，表面聊晚饭吃什么、借支笔，底下全在试探底牌与试压边界。
3. **动作打断长台词**：大段独白或陈述超过 3–4 行时，插入一次举杯、停顿 `(pause)`、对方打断 `--` 或环境干扰，保持现场感。
4. **声线与停顿**：说话人姓名全大写；停顿只用 `(pause)`；拖长音与欲言又止用省略号 `...`；括号提示简短克制，只在不写就会演歪时才标。

## 三、文档顶栏与保存格式

剧本草稿须以一级标题 `# 剧名` 起头，随后紧接 `FADE IN:` 与 `场01 INT./EXT. 地点 - 时间`（全片场号连续），末尾以 `FADE OUT.` 收束。写全片剧本草稿时按序列顺延构思、一次性饱满输出完整剧本（仅在触发 JSON 参数截断报错时依 `worker-policy` 按场次追加），经 `novel_screenplay_save_draft`（`类型: 剧本草稿`）校验入草稿区。
