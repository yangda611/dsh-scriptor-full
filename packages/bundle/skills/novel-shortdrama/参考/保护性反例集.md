# 短剧保护性反例与防改僵手册

> 审读与润色时参照本手册：目标是让剧本好看、像真人说话，而不是为了迎合机器阈值把好戏改碎。

## 一、合法节奏保护清单

1. **高压短连击（合法碎句）**：双方当庭对质、争分夺秒抢救或激烈互怼时，连续出现多句 2–4 字短台词属于正常快节奏交锋，不要为了凑单句平均长度强行往里添废字。
2. **安静情绪场与余波场**：亲人告别、隐忍落泪、真相大白后的死寂，允许节奏放慢和适当留白；只要观众情绪没掉线，不机械硬加吵架或扇耳光。
3. **行动坚持型冲突**：末日囤货、秘密备战、匠人修复等“一人做事＋外人质疑”类剧集，允许行动段落大于对白段落；此时由质疑者配角代观众发问，不硬把动作戏改成站着嘴炮。
4. **反派说黑话＋主角当场拆穿**：只要主角紧接下一句就用大白话拆穿对方装腔作势（例如“说人话，不就是想吞那五千万”），就属于极佳喜剧与爽感对比，不要误删反派那句装腔词。
5. **弱神态引出强结果**：如“他手一顿，紧接着把整叠文件狠狠甩在桌上”。后半句已带强物理动作结果，允许保留前半句神态过渡。

## 二、修复回退判据

精修后做二次对照，若出现以下任一情况，立刻退回修改前版本：

- 人物本来有棱角的毒舌或沧桑感被改成标准播音腔；
- 为了压低单句字数，把完整的一句算账硬切得支离破碎；
- 为了避开检查警告，生硬塞进与剧情无关的多余动作，打乱了原本流畅的戏剧情绪曲线。
