# 工序：短剧分集大纲与单元规划

## 适用场景

当契约的 `输出形态` 是 `短剧`，需要排出全季结构位、单元冲突链与各集具体戏眼时执行本工序。

## 写前按需加载

- 查阅 `参考/题材与爽点速查.md`，确认契约对应的 `市场` 与 `题材档`，核清核心爽点与禁忌清单。
- 查阅 `参考/情绪流单元链与往返法.md` 与 `参考/开篇钩子与断章公式.md`，排布单元边界、付费卡点与 A–I 反转标签。

## 第 1 步：单元链与季架构规划

- 单个主要矛盾或反派控制在 **20–30 集内收束完结**（3 分钟长档折半为 10–15 集），避免全季百集围绕同一个人原地打转。
- 单元切换做到「残渣生新矛、对手换层不换欲、主角弧光升级」，把首个竖屏付费墙卡在第一单元大清算与幕后黑手亮牌的交接集（第 10–11 集）。
- 调 `novel_shortdrama_plan_episodes`，传入 `市场`、`题材档`、`画幅`、`总集数`、`首胜集`（可选）、`付费集`（可选），取得各集钩子轮换位与排播锚点。

## 第 2 步：填满每集七项戏剧骨架

工具生成的只是结构槽位。针对本次授权批次（如第 1–5 集或第 1–10 集），逐集写实：

| 字段 | 写法要求 |
|---|---|
| `标题` | 凝练点破本集戏眼，避免抽象大词 |
| `钩子类型` | 对齐工具给出的身份钩／情感钩／顿悟钩轮换 |
| `反转标签` | 标明 `A–I` 主反转类型，连续 3 集不重复同标签 |
| `核心想法` | 一句话说透本集主角靠什么行动换取哪一口气 |
| `爽点与结算` | 写明打脸或揭露怎么落地，以及反派付什么可见代价 |
| `开场冲突` | 确定前 3 秒可见动作或具体死线数字，禁止日常铺垫 |
| `反转与结尾悬念` | 写出具体亮牌步骤（含核心物证），集尾用五大断章公式切在问题或半秒掀底处 |

## 第 3 步：建立连续性台账并呈报

- 在 `草稿区/剧本/短剧/全季连续性台账.md` 记下主角群当前筹码、核心秘密知情表、关键道具归属与单元伏笔。
- 将分集大纲与台账摘要汇总呈报作者，通过 `novel_authorize_batch` 取得一次批量托管批准后直接转入《单集剧本》连续生成。
