# 工序：单集剧本写作与连续性衔接

## 适用场景

依据已确定的分集大纲，连贯写出单集饱满可读的短剧剧本并落盘校验、审读、定稿。

## 写前按需加载与连续性准备

1. 写作第 `N` 集前（`N > 1`），先读取 `剧本/短剧/集NNN-1.md` 末尾（至少保留后半场收尾交锋与断章原貌）及 `草稿区/剧本/短剧/全季连续性台账.md`，核实伤势、持物、账目与已揭示秘密，避免跨集吃书。
2. 写作前查阅 `参考/戏剧工艺层.md` 与 `参考/台词七维诊断.md`。

## 正文排版契约（兼容渲染器与解析器）

1. 首行标题格式为 `# 集001：标题`（英文冒号或全角冒号皆可，不加书名号），紧跟单集元信息：
   `- 画幅：竖屏`（或 `横屏`）、`- 时长：90 秒`、`- 钩子类型：身份`（取 `身份`／`情感`／`顿悟`）、`- 核心想法：……`、`- 爽点：……`、`- 结尾悬念：……`。
2. **场头**：`集-场 日/夜／内/外 地点`，如 `1-1 日／内 会议室`（旧式 `## 场01.` 已废弃）。竖屏单集通常安排 **2–4 场**（至少主冲突场＋结尾余波场共 2 场，勿只写 1 场）。
3. **人物行与场景环境行**：`人物：林凡（外卖工服）、赵虎（金表男）` 与 `场景环境：雨夜门口，地上散着打翻的外卖盒。`
4. **镜头块与时间码**：
   `△【镜头01｜时间：00:00—00:42｜景别：近景｜角度：平视正面｜运镜：固定镜头】`
   常用景别：`远景` / `中景` / `近景` / `特写` / `中近景` / `全景`；常用角度：`平视正面` / `侧面平视` / `微侧平视` / `俯拍` / `极低角度俯拍`；常用运镜：`固定镜头` / `手持微晃` / `缓慢推进` / `微晃动` / `低机位平移推进`（若未定可填 `—`）。时间码按标准分秒写（满 60 秒进位为 `01:25`，勿写 `00:85`）。每条 `△` 动作行简短有力（≤40 字），避免孤立的「眼神微动/若有所思」。
5. **对白与停顿**：
   - `说话人（表演提示）：台词正文`（标注可写语速/音量/语调/尾音或简洁动作提示；画外音加「画外音，」；停顿只用 `(pause)`）。
   - 被打断用 `--`，欲言又止用 `...`；音效用 `【环境声：……】` 独立成行。
   - **每 2–4 句对白穿插 1 条强视觉 `△`**，保持连续纯对白不超过 6 行。
6. **剧末节拍表**：`【画面淡出黑场】` 后附 `## 节拍表`，逐行列明 `- 开场冲突：第 2 秒`、`- 反转：第 25 秒、第 70 秒`、`- 结尾钩子：第 86 秒（切在问题上）`。

## 实战写作与精修要点

- **开篇直接炸场**：首镜即强动作或核心数字死线，前 3 句立清敌我压迫关系，零寒暄零旁白科普。
- **15 秒四拍换挡**：0–15s 立事、15–45s 交锋、45–85s 亮牌结算（反派付可见代价）、85–110s 余波钩子。长档/横屏剧按两回合＋中段小钩推演。
- **物证与大白话同轮直给**：甩出道具、账号或规则时，紧接 1 句大白话点透金钱、生死或地位后果，不当谜语人。
- **快慢变速节奏**：3–6 字短促回怼与 8–16 字算账宣判交替咬合；保护自然语流，不因单句稍长强行切成碎渣。

## 落盘、审修与连续性沉淀

1. **保存草稿**：调 `novel_shortdrama_save_script` 直接提交完整 Markdown 剧本至 `草稿区/剧本/短剧/集NNN.md`（结构化 JSON 场景亦可用 `novel_shortdrama_render_episode`）。
2. **机器与语义双审**：跑 `novel_shortdrama_check_beats` 与 `novel_shortdrama_review_episode`，结合 `参考/保护性反例集.md` 与 `底本/短剧审读.md` 复核并经 `novel_record_review_findings`（模块 `短剧审读` + `短剧审读（语义）`）回写。
3. **修改与定稿**：有阻断项或明显干聊/黑话缺陷直接改稿重审，确认无误后调 `novel_shortdrama_settle_episode` 原子入档 `剧本/短剧/集NNN.md`，并顺手更新 `全季连续性台账.md` 进入下一集。
