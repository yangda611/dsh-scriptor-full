# 《夜市摊主》总纲（剧本圣经）

> 语言规则：说明/场景/动作文字一律中文；对白按目标市场语言（本剧对白语言：中文）。

类型：都市美食／身份反转／温情治愈；形式：12集连续短剧／约90分钟长片规格；三幕、十二集；文字目标：分镜拉片剧本每集约3,000—5,000字（含标点、场景环境、镜头参数、△站位/动作/表情描写、对白、环境音效与画面字幕），服从成片节奏，不为凑字数扩写。
叙事：陈默摆摊求生与身份揭晓为主线（A线），小满的身世与妈妈留下的铁锅为暗线（B线），老周的暗中调查与美食博主的追踪为辅线（C线）。

一、故事一句话

隐姓埋名的前米其林主厨陈默在夜市摆摊还债，却因一道失传的“小满炒饭”被美食博主盯上，女儿小满的出现逼他在尊严与真相之间做选择。

二、开篇承诺与中心问题

开篇：夜市收摊前，陈默拒绝了美食博主林晓十万买配方的出价。
悬念：1. 小满炒饭的配方到底从哪来；2. 陈默为什么离开米其林；3. 小满到底是谁的女儿；4. 老周为什么总在收摊时出现；5. 十万买配方的人下一次会出什么价。
主题：手艺与尊严比名声更难守；真正的传承不在招牌上，在人心里。
反题：靠噱头和流量换来的爆红，守不住一口锅的温度。

三、世界硬约束与地理

• 现实基底与唯一超自然规则：江南小城夜市，没有超自然设定；唯一的硬规矩是“小满炒饭”配方只传陈家人。
• 硬约束：
 1. 配方不外传：陈默答应过妻子，配方只做给家人吃。
 2. 三年之约：陈默发誓三年不碰米其林菜系，约满才能回头。
 3. 摊位到期：夜市东街的摊位租约只剩一个月，到期不续就得走。
 4. 小满的监护：小满的户口还在外婆家，陈默接不回女儿。
• 核心地理空间：
 1. 夜市东街：陈默的炒饭摊，路灯下最后一个摊位。
 2. 陈默出租屋：墙上贴着小满的奖状，桌上摆着妈妈留下的旧铁锅。
 3. 老周的报刊亭：夜市东街口，消息集散地。
 4. 米其林餐厅旧址：陈默离开的地方，如今改成了连锁快餐。

四、三段核心真相（作者事实，不等于所有角色已知）

陈默三年前离开米其林，带着一口旧铁锅到夜市摆摊还债；妻子去世后女儿小满住在外婆家，每周只来一次。
林晓的视频让“小满炒饭”一夜爆红，出价的人越来越多；老周查出当年的事另有隐情，配方外泄的源头不是陈默。
小满的身世揭开：铁锅是妈妈留下的，配方是妈妈口述的；陈默在夜市当众做完最后一道菜，接回了女儿。

五、主要人物与人物弧（全剧统一规范）

1. 陈默（35岁）：前米其林主厨，现夜市炒饭摊主。从逃避过去、只求还债，到为女儿重新掌勺，把手艺还给该给的人。（原剧本曾误标为：摊主[第1集]、厨子[第2集]，已全部统一为陈默）
2. 小满（8岁）：陈默的女儿，住在外婆家。从每周只来一次的客人，变成爸爸重新掌勺的理由。
3. 老周（约60岁）：夜市东街口报刊亭主。从看热闹的街坊，变成替陈默守住真相的人。
4. 林晓（26岁）：美食博主。从只追流量的博主，到明白有些味道买不走。

六、分集结构与时间锚点

• 第一幕：身份藏匿
 - 第1集（D1 夜晚）：收摊前最后一份炒饭，陈默拒绝了林晓十万买配方的出价。
 - 第2集（D2 白天）：林晓的视频发出去了，摊前开始排长队。
 - 第3集（D2 夜晚）：小满每周一次的探望，撞见了排队的长龙。
 - 第4集（D3 夜晚）：老周提醒陈默：有人在打听配方的来历。
• 第二幕：配方风波
 - 第5集（D4 白天）：出价的人找上门，陈默第一次动摇。
 - 第6集（D4 夜晚）：有人冒充陈默的配方摆摊，食客吃出了差别。
 - 第7集（D5 夜晚）：老周查到当年米其林后厨的旧事。
 - 第8集（D6 白天）：摊位租约到期，夜市要收回陈默的摊位。
• 第三幕：真相与归来
 - 第9集（D6 夜晚）：小满的身世揭开，铁锅是妈妈留下的。
 - 第10集（D7 白天）：陈默第一次对小满讲起妈妈的菜。
 - 第11集（D7 夜晚）：夜市最后一夜，陈默做了一道三年没做的菜。
 - 第12集（D8 清晨）：陈默接回小满，铁锅有了新的主人。
