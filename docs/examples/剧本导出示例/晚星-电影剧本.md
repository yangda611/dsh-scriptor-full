# 《晚星》总纲（剧本圣经）

> 语言规则：说明/场景/动作文字一律中文；对白按目标市场语言（本剧对白语言：中文）。

类型：现实悬疑／剧情；形式：短片／8场／三幕结构；文字目标：分镜拉片剧本约2页，约2分钟（1页≈55秒，见调研 §1.1；服从成片节奏，不为凑字数扩写）。
叙事：林晚星查清三年前大火真相为主线（A线），陈默隐瞒报警时间的真相为暗线（B线），阿辉洗清纵火嫌疑为辅线（C线）。

一、故事一句话

前消防员林晚星想查清三年前那场夺走队友性命的大火真相，却发现真相指向她最信任的人，而真正的纵火者还藏在暗处。

二、开篇承诺与中心问题

开篇：深夜，阿辉走进面馆，带来一张旧照片：起火点附近有人影。
悬念：1. 三年前的大火到底是意外还是人为纵火；2. 起火点附近的人影是谁；3. 陈默到底隐瞒了什么；4. 真正的纵火者是谁；5. 阿辉的嫌疑能不能洗清。
主题：真相不是用来报复的，是用来继续生活的。
反题：有些事翻出来对谁都没好处，不如让过去过去。

三、世界硬约束与地理

• 现实基底与唯一超自然规则：现实世界，无超自然设定。
• 硬约束：
 1. 大火发生在三年前，带走了林晚星的队友。
 2. 阿辉是三年前火场里被救出来的孩子，如今是纵火案的嫌疑人。
 3. 报警时间曾被改动。
• 核心地理空间：
 1. 深夜面馆：林晚星开的面馆，江城。
 2. 消防队旧址。
 3. 废弃仓库：旧仓库地块，纵火目标。

四、三段核心真相（作者事实，不等于所有角色已知）

【第一阶段：起疑（第1—2场）】阿辉带来旧照片，起火点附近有人影，大火可能不是意外。
【第二阶段：求证（第3—6场）】监控证实大火是有人故意纵火；陈默承认是他隐瞒了报警时间，但纵火者另有其人，阿辉是被栽赃的；仓库里找到最后的证据。
【第三阶段：了结（第7—8场）】证据交给警方，阿辉洗清嫌疑；陈默上门道歉，林晚星给他盛了一碗面。

五、主要人物与人物弧（全剧统一规范）

1. 林晚星（32岁）：前消防员，现开深夜面馆。从非查清真相不可，到明白真相是用来继续生活的。
2. 陈默（45岁）：消防队前队长，林晚星的师父。从隐瞒撒谎保队伍名声，到上门道歉。
3. 苏晴（29岁）：调查记者，林晚星的老同学。从想要一篇能拿奖的独家报道，到帮老同学讨一个公道。
4. 阿辉（22岁）：三年前火场里被救出来的孩子，如今是纵火案的嫌疑人。从害怕没人相信，到洗清嫌疑。
5. 工作人员：档案室工作人员。按规矩拒绝调阅涉密记录。
6. 民警：警局民警。核对证据链后立案，阿辉的嫌疑洗清。

六、三幕结构与时间锚点

• 第一幕：起疑（D1 深夜—清晨）：阿辉带来旧照片，林晚星开始怀疑大火不是意外。
• 第二幕：求证（D1 白天—夜晚）：监控证实人为纵火，陈默承认隐瞒，阿辉是被栽赃的；仓库里找到最后的证据。
• 第三幕：了结（D2 白天—黎明）：证据交给警方，阿辉洗清嫌疑；陈默道歉，林晚星给他盛了一碗面。
