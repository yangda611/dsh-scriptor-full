# 《晚星》电影剧本

- 场数：8 场
- 预估页数：约 2 页（一页约一分钟是经验法则，实测约 55 秒/页，见调研 §1.1）

> 导出说明：本文件分两层——编剧层（分场景剧本）与导演层（分镜头表），两层不要混写。
> 音效写进动作行，不用 `SFX:` / `MUSIC:` 独占行（那是 BBC 广播剧格式）；停顿只用 `(pause)`，不用 `(beat)`；
> 音乐提示只进分镜头表音乐栏。格式来源：调研 docs/research/film-drama-research.md §1.1–§1.3。

## 编剧层

FADE IN:

场01 INT. 面馆 - 深夜

面馆打烊了，林晚星擦着桌子，门外传来脚步声。

一个年轻人推门进来，浑身湿透，手里攥着一张旧照片。

林晚星
这么晚了，吃面还是避雨？

阿辉
我叫阿辉。三年前，是你把我从火里背出来的。

林晚星
（pause）
你想说什么？

阿辉
那场火不是意外。你看这张照片，起火点旁边站着一个人。

场02 EXT. 消防队旧址 - 清晨

天刚亮，林晚星站在消防队旧址门口，陈默从里面走出来。

陈默
你又来了。当年的事，翻出来对谁都没好处。

林晚星
对谁没好处？对死去的人，还是对活着的人？

陈默
晚星，听师父一句，别查了。

场03 INT. 档案室 - 日

林晚星把申请表推过去，工作人员摇了摇头。

林晚星
我就看一眼出警记录，三年前的。

工作人员
涉密，没有批条不能调。

苏晴
那我们换个办法。我认识管监控的人。

场04 INT. 报社办公室 - 日

苏晴把笔记本电脑转向林晚星，屏幕上是一段模糊的监控。

苏晴
看清楚了，起火前十分钟，有人提着油桶进去。

林晚星
所以那场火，是有人故意放的。

苏晴
报社不敢发这段，得罪开发商，明天我就得走人。

林晚星
那我自己去找剩下的一半。

场05 EXT. 天台 - 夜

风很大，陈默站在天台边上，警笛声由远及近。

林晚星
报警时间是你改的，对不对？

陈默
我以为瞒下来，是在保护所有人。

林晚星
你保护的是谁？说出来。

陈默
（pause）
纵火的人不是阿辉。有人栽赃给他，我当时不敢说。

场06 INT. 废弃仓库 - 夜

仓库门被人从外面顶住，林晚星和阿辉被堵在里面。

林晚星在墙角摸到一只打火机，上面刻着开发商的标志。

阿辉
那天晚上我看见了，那个人戴着帽子，往墙角倒东西。

林晚星
别怕，躲到我身后。

林晚星
证据齐了。这一次，他跑不掉。

场07 INT. 警局 - 日

林晚星把证据袋放在桌上，苏晴和阿辉站在她身后。

林晚星
照片、监控、打火机，每一环的来源我都写清楚了。

民警
立案。阿辉，你的嫌疑洗清了。

阿辉
谢谢你，林姐。

场08 INT. 面馆 - 黎明

天亮了，林晚星重新支起面摊，陈默站在门口，手里提着一袋米。

林晚星给他盛了一碗面，热气升起来。

陈默
我来道歉的。不求你原谅。

林晚星
进来吧，吃碗面。

林晚星
真相不是用来报复的，是用来继续生活的。

FADE OUT.
