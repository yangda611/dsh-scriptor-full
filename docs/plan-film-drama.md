## 调研结论（2026-11-10，76 条来源，见 docs/research/film-drama-research.md）

**专业剧本格式（约 28 条来源）：**
- 美式标准：12 磅 Courier；“一页 ≈ 一分钟”是经验法则（实测约 55 秒/页）；长片 90–110 页。
- 六大元素各有固定缩进：场景标题、动作行、角色名、台词、括号提示、转场。
- 场景标题三段式全大写：`INT./EXT. + 地点 + 时间`；动作行现在时、只写看得见/听得见的；角色首次出场姓名全大写。
- 括号提示小写、简短、少用；台词停顿三种写法来源间有分歧（`(beat)`/`(pause)`/省略号），工具内定一种（ScreenCraft 明确反对用 `(beat)` 表停顿）。
- 镜头提示在 spec 剧本里应克制，拍摄剧本才详写；景别/角度/运镜属分镜头层。
- 音效在电影剧本里是动作行内关键音效词大写；`SFX:`/`MUSIC:` 独占一行是 BBC 广播剧格式，不是电影剧本格式——音响/音乐应放在分镜头表单列。
- 中文格式：无专门协会标准、只是约定俗成；分场景剧本标头为 `场号. 地点 时间 内/外`，对白为 `说话人：内容`；分镜头剧本是导演的表格。
- **结论：输出两层——编剧层（分场景/master scene）+ 导演层（分镜头表），不要混写。**

**短剧惯例（约 22 条来源）：**
- 竖屏：9:16，单集 60–120 秒、每集 2–4 场、台词 180–360 字，全季 60–100 集；广电第 16 号令（2026-09-01 生效）定义微短剧为单集 20 分钟以下。
- 开头 3–5 秒内必须进冲突，不铺场景、不放片头；静音预览也要看得懂。
- 每 20–30 秒一个转折，90 秒一集至少转两次；每集结尾 5–10 秒必须留钩子，切在问题上不是答案上；三类钩子（身份/情感/顿悟）轮换。
- Filmustage 四段 Beat Engine：Hook 0–15 秒、Friction 15–60 秒、Spike 60–90 秒、Button 最后 5–10 秒。
- 前三集定生死（第 1 集身份钩、第 2 集情感钩、第 3 集顿悟钩），主角第一次胜利不得晚于第 5 集。
- 付费卡点：海外首个付费集最常见第 11 集（免费中位数约 9 集）；国内前 10–15 集免费，此后多卡点（约第 8–16/25–30/50 集）。
- 台词要短：中文指南约每句 <12 字；每集只容一个想法；对白即动作。
- 横屏 vs 竖屏是两种产品：横屏/中剧单集 10–20 分钟、20–30 集、起承转合、精品叙事导向；同一 IP 实例《好一个乖乖女》竖屏 88 集×3 分钟 vs 横屏 29 集×15 分钟。

**题材库 海外 vs 中文（约 26 条来源）：**
- 海外六大套路：亿万富翁（权力不对等）、黑手党、狼人/命中注定伴侣、重生/反击、隐藏身份、系统；279 部标题词频：婚姻/离婚 53、黑手党 28、狼人 26。
- 海外榜单：ReelShort 收入第一是狼人《The Luna's Second Choice》，DramaBox 历史第一是隐藏身份《Your Loser Husband Is A Big Shot》。
- 海外地域分化：北美女性爱狼人/吸血鬼+亿万富翁复仇、男性爱末世+黑手党；东南亚男女皆宜、可直接复用国内题材；拉美爱高情绪强度。
- 海外避开：纯修仙、复杂东方神话、长升级线不要直接出口西方；赘婿、婆媳外国观众无感；出海靠字幕/配音或洛杉矶翻拍。
- 国内男频：赘婿逆袭、战神归来、神豪、神医、修仙玄幻、重生逆袭、权谋；核心是身份反转。
- 国内女频：霸总甜宠、重生复仇、大女主（2025–2026 年无 CP 事业型成爆款模板）、闪婚、萌宝、宫斗宅斗、婆媳、年代、种田；2023 年女频占比反超男频。
- 命名：中文男主姓顾/傅/厉/陆/霍/司、女主姓苏/沈/夏/林/安/温/姜，地点京市/江城/A 市；海外狼人题材用 Selene/Jackson/Alexander + Alpha/Luna/Omega 等级称谓。
- 国内审查硬门槛：2024-06-01 起未备案不得上线；按投资额分三类审核；片头须标许可证号或备案号；11 项禁区内容；AI 生成须标标识；片名禁恶俗与极端复仇暴戾。
- 剧名词表会过期：2025 年初改名潮中“总裁/战神/神豪”大减、“爱”成最高频情绪词，题材库命名词表需留更新接口。
- **暂未查到、需再确认 7 项**（见调研笔记第 5 节）：BBC 官网原站模板页、FlexTV 专属爆款榜单、各平台逐条成文的审核细则、中文剧本格式行业协会标准、电影剧本音乐提示统一格式、竖屏短剧分镜单镜时长统一标准、海外命名习惯除狼人题材外的成文总结。

## 摸底结论（2026-11-10，代码只读核查）

- 全仓 grep「剧本 / screenplay / fountain / 分场 / 场景标题」**零命中**——剧本是全新领域，无现成格式/目录/解析器可复用。
- 小说侧有一套严格的“真源文件 + frontmatter + Git 提交 + 门禁”契约，改造必须顺着它走，不能另起一套。
- DSH 清单在 `packages/bundle/package.json`（无独立 dsh.json）；技能由 `@deepseek-ai/dsh-skill-filesystem` 从 `packages/bundle/skills/` 扫描加载；工具 31+4 个在 `packages/bundle/src/novel-tools.ts`，注册只到主 Agent scope；`release:smoke`（隔离 DSH host 安装测试）是 DSH 兼容性的唯一端到端门，本地 vitest 测不出来接线问题。
- 新技能要同步 4 处：SKILL.md 落盘、`artifact-contract.mjs` 的 skills + referenceDocs、`tests/skills.spec.ts` 的 EXPECTED_SKILLS、`novel-director` 路由表。SKILL.md description 含 `:` 必须加引号（有过 `ch: 提交` 事故）。
- 新 frontmatter 字段必须先登记进白名单（`repo/document-fields.ts` 等），否则工具直接拒绝；旧书加字段必须走 `novel_preview_book_upgrade` 整仓预览 → 作者批准 → 应用，不能静默补写。
- 卷/章寻址是全仓假设，短剧的集/场塞不进去，要另设平行寻址键（集/场或幕/场），不要复用卷/章参数名。
- 剧本定稿建议新建顶级目录（如 `剧本/`，与 `定稿/` 平行），不要复用 `定稿/`（会污染小说导出）。

## 实施顺序（摸底后修订：前置先行）

先定三项共同前置（写进 `docs/book-format.md` 后再动手）：契约 frontmatter 字段名（市场/输出形态）+ 剧本定稿目录 + 集/场寻址键。然后做项目创建与题材库，再并行电影与短剧两条管线，收尾做剧本导出。每一步跑 `vitest`，接线与打包改动后加跑 `pnpm release:build` + `pnpm release:smoke`。

## 目标

把 DSH Scriptor v8.4.1（长篇小说工作台，DeepSeek Harness 插件）改造成 AI 影视剧项目组工具，输出三种东西：

- **短剧**（横屏/竖屏，单集 1–3 分钟，几十到上百集）
- **电影剧本**（专业影视级格式）
- **小说原文**（现有流程不动）

创建项目时选两样：**市场**（海外 / 中文 → 决定题材库）+ **输出形态**（短剧 / 电影剧本 / 小说）。
最终输出永远是中文（团队自己拿去拍）。

## 三条硬要求（用户原话，底线）

1. **DSH 适配是底线**：它是 DSH 的拓展插件，必须更适配 DSH，装进去得能用。绝不能破坏插件清单（manifest）、技能定义、工具注册和 DSH 集成点。改完每一步都要验证：`pnpm build` 通过、`vitest run` 通过、仓库自带的 release/smoke 检查能跑的要跑通。任何会让 DSH 加载失败的改动都不许做，宁可换 DSH 兼容的做法。
2. **简单易用**：让不会用的人也能会用。创建项目要有清晰的引导选择和合理的默认值，提示用大白话、别堆术语，新手文档（docs/user/beginner.md 等）要同步更新到新流程。
3. **上网实际调研，不许凭空编**：题材库（海外/中文套路、人物名、文化设定、禁忌）、剧本格式规范、短剧惯例，都必须基于真实的网上调研。调研来源写进代码/文档注释或调研笔记（docs/research/film-drama-research.md）。

## 已批准的设计（用户 2026-11-10 确认）

- 底子共用：作品契约、世界书、大纲这三件套，三种形态都用，不重写。
- 三条流水线：
  - **小说**：现有流程不动（细纲→备料→起草→八维审读→批改→作者裁决→定稿）。
  - **电影剧本**：故事稿（精简版小说：人物小传 + 情节主线 + 关键转折）→ 改编（分场大纲 → 剧本草稿 → 审读）。
  - **短剧**：分集钩子/爽点大纲 → 单集剧本 → 审读。短剧和电影各用自己的节奏模板（短剧和电影是两套节奏：爽点密度、钩子力度不同）。
- 剧本格式统一按专业影视级：场景标题、动作、角色、台词、括号提示（停顿/语气），再加镜头、音效、音乐提示，作为导出标准。
- 题材库两套：海外题材库和中文题材库（套路、人物名、文化背景、禁忌），创建时选定。
